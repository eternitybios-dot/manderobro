# 深層 — Infinite Mandelbrot

スマホで見れる、マンデルブロ集合を**永遠に自動拡大**するフラクタル探索アプリ。

## 使い方

1. 開くと自動で拡大が始まります
2. 下の **SPEED** バーで拡大スピードを自由に変更（停止〜最速）
3. ピンチで手動ズーム、ドラッグで移動もできます
4. 「配色」でカラーパレットを切り替え
5. 限界まで潜ると、別の名所へシームレスに遷移してまた潜り続けます

## 開発

```bash
npm install
npm run dev
```

本番ビルド:

```bash
npm run build
npm run preview
```

## 技術

- WebGL2 フラグメントシェーダで描画
- double-float（疑似倍精度）で深いズームに対応
- タッチ操作（ピンチ / ドラッグ）対応
