# 深層 — Infinite Mandelbrot

タップで場所を選んで、**ひとつの映像のまま途切れず拡大**するスマホ向けフラクタル探索アプリ。

## スマホで見る

**https://rawcdn.githack.com/eternitybios-dot/manderobro/1aa0dba9541f3438e4f63e71318f3637bd2ef24b/site/index.html**

(このURLはコミット固定です。最新版は `npm run build:single` で `site/index.html` を再生成してコミットし、新しいコミットハッシュのURLを使ってください)

## 本物のディープズーム

擬似的な繋ぎ(Julia へのクロスフェードなど)は使いません。**摂動法(perturbation)**で描画します:

- 視点の中心は BigInt 固定小数点で任意精度に保持
- 中心の基準軌道 Z_n を高精度で計算し、GPU は各ピクセルの微小な差分 δ だけを float32 で反復(リベース付き)
- これで **×10^26(logZoom 60)** まで、1本の連続した本物のマンデルブロ映像として潜れます
- 自動操舵が常に集合の境界に張り付くので、どこまで潜っても構造が途切れません
- 精度の底に達すると、映像を切らずにそのままゆっくり浮上し、別の谷へ潜り直します

## 操作

- タップ: 拡大する場所を選ぶ(映像は切り替わらず、そこへ滑らかに向かう)
- ドラッグ: 視点をずらす / ピンチ: 拡大縮小
- SPEED: 速さ変更(初期値はゆっくり)

## 開発

```bash
npm install && npm run build && npm run preview
APP_URL=http://127.0.0.1:4173/ npm run verify:motion
npm run deploy
```

※ 旧ライブURL (elastic-rift-ualaf37.shipstatic.com) は旧実装のままです。shipstatic に配信し直す場合は `npm run deploy` を使ってください。

`verify:motion` は数値カウンタではなく**映像そのもの**を検証します:

- 凍結ズーム整合性: 中心固定で正確に2倍潜ったフレームが、直前フレーム中央部の拡大と一致するか(旧実装の偽ハンドオフ帯 logZoom 9.5–12.3 を含む)
- 自動潜行を1分間走らせ、連続フレーム対が実測のズーム+パン変換で互いに再現できるか(カットやクロスフェードはここで必ず落ちる)
- 全深度でフレームに実構造があるか / 潜行中はズームが単調か / 中心が瞬間移動しないか
